# Repository Source Map

The first inventory scans documentary Markdown/RST/text under `docs/`,
`logs/`, `archive/`, `fleetcore/`, `projects/`, `intentforge/`, `tools/`, and
`toys/`, plus key top-level guidance and charter files.

Generated inventory: [`../registry/documents.json`](../registry/documents.json).

Excluded from the first pass: binary assets, caches, vendored dependencies,
build output, virtual environments, and routine source code. Code may be cited
later as implementation evidence when documentary sources are insufficient.
