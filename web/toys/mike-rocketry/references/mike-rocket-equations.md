# Mike's rocket equations

Primary source: <https://github.com/mds2/rocketry>

The interactive Version 1 preserves the notebook's core non-relativistic
comparison:

\[
\Delta v_{\mathrm{constant}} = \sqrt{2R_e}\ln(m_i/m)
\]

\[
v_{e,\mathrm{optimal}}(m)=\frac{\sqrt{2R_em_im_f}}{m}
\]

\[
\Delta v_{\mathrm{optimal}}(m)
=\sqrt{2R_em_im_f}\left(\frac{1}{m}-\frac{1}{m_i}\right).
\]

The final gain depends only on \(r=m_i/m_f\):

\[
G(r)=\frac{r-1}{\sqrt r\ln r}.
\]
