OPTIONAL COMPANY

Why does this work?

These are Loesch numbers: integers that can be written as x² + xy + y². The toy checks the exact form, rather than guessing from a short list.

Hint 1 · start small

The introductory run is 1, 7, 13, 19. Try changing one control at a time and look for a witness that stays pleasantly small.

Hint 2 · inspect the endpoint

For 35 terms, the endpoint is start + 34 × step. A low endpoint is interesting, but it is not evidence that it is the smallest possible endpoint.

Plain-language explanation

The expression is a three-cornered number machine. For each term, we ask whether some integer pair lands exactly on it. A witness is that pair; a verified failure means the exact arithmetic test rules the term out.
