# CAPTAIN-WORKBENCH-BEAST-IMAGE-0.1

1. **Originating intent** — Admiral ordered a priority proof of Live Captain
   as a major Monad architecture concept. Monadic Beast Lab is the first test
   instrument, not the purpose or boundary of the concept. The Admiral
   explicitly chose a small live proof over a robust platform.
2. **Verified starting state** — Beast Lab creates a deterministic recipe,
   SVG schematic, and procedural canvas interpretation. Live Captain Private
   Conference owns a site-wide signed session and Gemini provider, but exposes
   conversation only.
3. **Objective** — Prove an event-driven path that begins only with a live
   human button press, visibly exposes Captain-pipeline activity, and returns
   one generated artifact into the originating instrument.
4. **Scope/exclusions** — One `beast.image.enhance` capability; one model call
   per job; five submissions per UTC day; durable receipt and quarantined
   source/result. No arbitrary prompts, repository tools, automatic retries,
   Tripo submission, publication, or claim that the transient Codex CLI turn
   is a daemon.
5. **Authority/boundary** — For this experiment, Private Conference sign-in
   and access control are explicitly excluded. A same-origin button event
   submits the current recipe and schematic. The bounded adapter validates
   input, owns the Captain prompt, performs one generation, and records
   observed state. Browser polling observes and projects activity.
6. **Acceptance** — A valid request returns 202; job progresses
   queued → running → succeeded/failed; exactly one request is recorded;
   successful artifact remains private and downloads from Beast Lab; failures
   remain visible and do not publish or enter Tripo.
7. **Rollback** — Disable/remove `living-captain-workbench.service`, remove
   `/captain-workbench-api/` Caddy route, and revert Beast Lab enhancement
   panel. Durable receipts can remain archived.
8. **Actor** — Captain / Codex CLI, with Gemini image model as bounded provider.
9. **Evidence/state** — **Interactive proof staged for commissioning.**
   The button now starts one live image job, shows preparation, generation,
   return, and completion progress, then reveals the downloadable result.
   Per Admiral direction the proof has no sign-in or access-control flow.
   A minimal listener is technically required to receive the browser event;
   it is not presented as the interactive Codex turn or as a robust Captain
   platform. `/home/cgl/cmd.sh` installs the updated proof service.
