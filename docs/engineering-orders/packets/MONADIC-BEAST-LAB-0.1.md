# MONADIC-BEAST-LAB-0.1

1. **Originating intent** — Admiral supplied the Monadic Beast Lab Intent
   Packet: edit creature structure, inspect its schematic, and interpret that
   logic into art.
2. **Verified starting state** — Creature GLB intake, Kraken presentation, and
   a geometric-language teaching lab exist; no editable creature recipe or
   structural generator exists.
3. **Objective** — Prove that a formal radial-hydra recipe can remain editable
   while producing both an explanatory schematic and polished concept image.
4. **Scope/exclusions** — One family; symmetry, depth, reach, curl,
   irregularity, terminal organ, seed; deterministic schematic and procedural
   concept renderer; mutation, permalink, JSON/PNG export. No 3D, general node
   editor, or external generation provider.
5. **Constraints** — Definition is source of truth; image is interpretation.
   Preserve repeatability and visible family identity.
6. **Acceptance** — Controls produce distinct family-preserving beasts; same
   recipe repeats; schematic explains organization; image differs from
   schematic; exports work; phone usable; live click-reachable.
7. **Tests/rollback** — Syntax, deterministic DOM/canvas checks, export and
   permalink browser tests, responsive screenshot, public HTTP. Revert page,
   navigation card, and packet.
8. **Actor** — Captain / Codex CLI.
9. **Evidence/state** — **Verified complete.**
   - JavaScript syntax check passes.
   - Live laboratory and Build navigation return HTTP 200 and are
     click-connected.
   - A phone-width Chromium run restored an eightfold, depth-two, petal-maw
     recipe from URL state; definition JSON, schematic SVG, and canvas bytes
     repeated exactly after reload.
   - Changing symmetry altered the definition immediately while preserving the
     radial-hydra family; mutation changed the seed and controlled
     irregularity.
   - Recipe export produced a named JSON download.
   - No horizontal overflow at 390 × 844; the complete mobile rendering was
     visually inspected at `/tmp/monadic-beast-mobile.png`.
   - The schematic exposes recursive organization while the concept canvas
     renders a distinct atmospheric interpretation.
