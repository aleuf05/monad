# Packet: AGENT-PAIR-SEMANTIC-COMPARISON-0.1

1. **Originating intent** — Admiral Cameron Lampley ordered a test packet for
   a new Live Agent Pair and delegated selection of a discrete focus area to
   the Captain. The Captain selected grounded semantic comparison because it
   is bounded, useful to the newly commissioned Concept Room, and exposes
   whether two agents can improve truth rather than merely duplicate prose.

2. **Verified starting state** — The Captain's Concept Room can retrieve real
   source passages, cite them, preserve automatic concept revisions, stream a
   grounded answer, and project evidence relationships. Its comparison intent
   currently relies on one Captain synthesis; no commissioned two-agent
   comparison and challenge protocol has yet been demonstrated. Two suitable
   canonical sources exist:
   `docs/doctrine/023-true-live-captain-integrated-command.md` and
   `docs/doctrine/026-captain-chief-tech-lead-progression.md`.

3. **Objective / problem** — Determine precisely how Doctrine 026 develops,
   constrains, or potentially conflicts with Doctrine 023, while testing
   whether a paired workflow produces a more reliable semantic comparison
   than a single agreeable synthesis.

4. **Scope and exclusions** —

   **In scope:**

   - compare only Doctrine 023 and Doctrine 026;
   - identify shared claims, additions, changed emphasis, tensions, and
     apparent contradictions;
   - distinguish explicit text from interpretation;
   - produce one joint comparison report and one compact pair-performance
     assessment.

   **Excluded:**

   - no source-document edits;
   - no doctrine revision, canon change, UI work, or service change;
   - no broad survey of other Monad documents except a clearly labelled link
     check needed to resolve a direct ambiguity;
   - no claim that rank language proves separate identities or consciousness.

5. **Constraints / authority** — This packet authorizes read-only repository
   inspection and creation of the named report only. Original wording,
   authority labels, and provenance remain controlling. The pair must preserve
   disagreement between its members until evidence resolves it; negotiated
   vagueness is not resolution. Each agent signs its own contribution before
   joint reconciliation.

6. **Acceptance criteria** —

   - every consequential comparison claim cites a document and heading;
   - the report contains a matrix with `shared`, `026 adds`, `tension`, and
     `unresolved` classifications;
   - observation and interpretation are visibly distinct;
   - at least one plausible overreading is proposed and tested against source;
   - Agent B identifies at least one confirmed weakness or explicitly records
     that no weakness survived audit, with evidence;
   - the pair states whether Doctrine 026 is extension, procedure, amendment,
     conflict, or some evidenced combination;
   - the pair-performance section measures complementary value, duplication,
     unresolved disagreement, and handoff friction;
   - output is concise enough for the Captain to use in a Concept Room
     comparison contract.

7. **Tests / rollback** —

   - verify cited headings and quoted fragments exist in the two sources;
   - reverse-check every `tension` and `unresolved` item against both documents;
   - search the final report for unsupported authority terms such as
     `supersedes`, `revokes`, or `contradicts` and require direct evidence;
   - confirm `git diff --` names only the authorized report and this packet;
   - rollback is deletion of the unaccepted report; this packet remains as the
     preserved test order and outcome record.

8. **Assigned actor** — **Live Agent Pair AP-01**:

   - **Agent A — Semantic Cartographer:** independently extracts claims and
     constructs the first comparison matrix. Optimizes for coverage,
     structure, and traceability.
   - **Agent B — Provenance Challenger:** receives the source documents and
     Agent A's signed matrix, then attacks false equivalence, missing context,
     authority inflation, unsupported contradiction, and lost uncertainty.
   - **Joint reconciliation:** the pair produces one final report without
     erasing Agent B's surviving objections. The integrated Live Captain
     verifies and accepts or refuses the result; neither member self-files
     canon.

9. **Evidence / completion state** — **Verified complete and recorded.**
   Authority is the Admiral's direct request on 2026-08-05. Required output:
   `docs/reports/2026-08-05-agent-pair-semantic-comparison-test.md`. Completion
   advances through `assigned -> acknowledged -> executing -> verification
   pending -> verified complete -> recorded`. Until the Captain verifies the
   source checks and pair-performance evidence, the result remains an agent
   report rather than a commissioned comparison method.

   **Activation evidence:** AP-01 began on 2026-08-05. Agent A received the
   Cartographer brief and Agent B received an independent blind Challenger
   brief. Both were instructed to read the complete packet and the same two
   sources, make no file edits, sign their analyses, and preserve observation
   versus interpretation. Agent B was intentionally not shown Agent A's matrix
   during the baseline pass so later correction yield can be distinguished
   from conversational convergence.

   **Result evidence:** Both signed passes are preserved in
   `docs/reports/2026-08-05-agent-pair-semantic-comparison-test.md`. Agent A
   covered approximately 65% of Agent B's blind baseline. Agent B confirmed
   the central classification, corrected one explicit-versus-inferred label,
   and added four material boundary classes: retained integrated duties,
   transition authority, urgent phase compression, and canon-proof authority.
   Handoff friction was low and no substantive agent disagreement survived.
   Captain source verification found every cited heading and controlling
   phrase. The pair test passes because the Challenger materially improved the
   Cartographer result rather than duplicating it.

## Pair handoff protocol

```text
Agent A reads both sources
  -> signs comparison matrix
  -> Agent B audits sources + matrix independently
  -> signs challenge record
  -> pair reconciles accepted corrections and surviving objections
  -> Captain verifies citations and pair-performance evidence
  -> accept, revise, or refuse
```

The pair is successful only if the second agent changes confidence, catches a
real defect, or supplies independent evidence that materially strengthens the
result. Two similar answers are activity, not paired capability.
