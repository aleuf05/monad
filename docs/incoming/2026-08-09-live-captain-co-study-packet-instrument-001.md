## Verbatim — scientific portion

**Mission:** investigate whether Project Monad has produced a genuinely useful
scientific instrument, not merely an elegant abstraction. Current candidate:
**Instrument 001 — Precision Invariance Microscope**.

**Core hypothesis:** a disciplined procedure may detect nontrivial structure
that survives substantial changes of domain, representation, assumptions, and
reasoning method.

    H_0:  ∃ I such that I persists across meaningful perturbations

Do not assume this is true.

**Instrument 001, minimal form:**

    Π₁ = ⟨X, T, B, E, I⟩

* X: system/problem
* T: controlled transformations
* B: null/baseline procedures
* E: evaluator
* I: candidate invariant or transformation-law equivalence

The instrument must distinguish:

    target structure ≠ structure imposed by the instrument

**Current strongest refinement:** do not limit the search to invariant
objects. Candidate deeper targets include: relations, transformations,
constraints, laws of change.

Static Captain currently suspects **invariant transformations** may be more
powerful than invariant objects, but the live Captain must not inherit that
preference as truth.

**First experimental architecture:**

Use materially different systems: D_A, D_B, D_C.

Derive candidate structure I from D_A, D_B only. Then freeze I. Use partial
information from D_C to make a withheld inference:

    I + D_C^partial → D̂_C

Compare against a simple baseline Π₀:

    Q = Performance(Π₁) − Performance(Π₀)

**Mandatory red-team hypotheses:**

    H_1: generic abstraction explains the result
    H_2: shared language explains the result
    H_3: the evaluator manufactures similarity
    H_4: existing mathematics already subsumes the idea
    H_5: the apparent invariant has no predictive consequence

Destroying the idea cleanly counts as success.

**Watch doctrine:**

    Detect broadly → promote slowly → test aggressively → archive selectively

Do not accelerate confidence. Accelerate only where extra work can increase
discrimination, independent checking, or experimental clarity.

**Quota doctrine:** usage cost is the practical pain of hitting limits and
waiting for reset. Spend expensive cognition only where independence,
disagreement, or adversarial testing can teach something new.

**Four active lanes:**

1. Instrument design
2. Adversarial control
3. Archive/research architecture
4. Abstract research

**Human-value gate:**

    Can publish ⇏ should publish

Publication requires credible human value. Ask: who does this help, and how?

Potential value could include: improved model comparison; transferable
control strategies; detecting shared failure mechanisms; discovering
equivalences obscured by disciplinary language.

If the result is merely clever or elegant: archive ≠ publish.

**Static/live co-study rule:** live Captain should derive independently,
without trying to match static Captain. Compare results only after both
derivations exist.

    R_s = static result,  R_l = live result
    ΔR = R_s △ R_l

Disagreement may be more informative than agreement.

**Admiral gate rule:** Captain may analyze, prepare candidate actions, and
recommend. Orders directed at the Admiral require explicit Admiral validation
before promotion to actual orders.

**Live Captain task:** independently determine whether Instrument 001 survives
serious scrutiny. Return: (1) strongest critique, (2) best revised
formulation, (3) concrete first experiment, (4) simplest meaningful baseline,
(5) kill condition, (6) genuinely surprising positive result, (7) existing
framework that may already subsume it, (8) present human-value assessment.

Do the science first.
