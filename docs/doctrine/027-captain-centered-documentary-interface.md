# Doctrine 027 — Captain-Centered Documentary Interface

**Authority:** Admiral Cameron Lampley, 2026-08-05 — *"the TRUE doc viewer
must be controlled by LIVE Captain"*, *"LLM-centered CONCEPT EXPLAINER"*, and
*"don't polish the turd, build the gem"*, followed by an explicit order to
capture the design and make the resulting ruling canon.

**Status:** Canon.

## Ruling

Monad's primary documentary interface is the Living Captain explaining
concepts, history, evidence, disagreement, and change through live dialogue
and voice. It is not a file list with increasingly elaborate reading chrome.

The division of responsibility is:

```text
Admiral navigates meaning
Captain navigates documents
sources remain inspectable evidence
```

## Consequences

- Concepts, questions, decisions, conflicts, and historical movement are the
  primary navigation objects.
- Documents remain authoritative sources and must be reachable from citations.
- The Captain distinguishes source observation, synthesis, inference,
  uncertainty, refusal, proposal, and canon.
- Spoken explanation is a first-class ingestion path. The visible interface
  retains the deeper chart and exact evidence.
- Captain-created memory may organize inquiry automatically but does not
  silently become source truth or canon.
- New evidence revises understanding without erasing the prior state.
- Documentary capability belongs inside the existing Living Captain and Root
  Console rather than in a shadow application or duplicate corpus.

## Design freedom

This doctrine fixes the interaction center, not one permanent layout,
retrieval algorithm, model provider, or visualization. Concept maps, history
rivers, retrieval methods, and voice behavior should improve from measured
use while preserving provenance and direct source inspection.

## Acceptance

The doctrine is demonstrated when the Admiral can ask the Captain what an idea
means or how it changed, receive a useful spoken and visible explanation
grounded in real sources, inspect the evidence, continue the inquiry in the
same room, and later see how the working understanding was revised.
