# Doctrine 019 — General Orders

**Authority:** Admiral cgl, 2026-08-05 — *"GENERAL ORDERS"*, then
*"MAKE CANON"*.

Standing. These are not advice; they are the orders the ship runs under.
Each is here because it was paid for on 2026-08-05, and each names what it
cost.

---

## I. Ask what else produces this value

If a second condition yields the same reading, you are not measuring. You
are guessing with a number in your hand.

`systemctl is-active` returns `inactive` for a service that was stopped
**and** for a unit that was never installed. Read five times as the first;
it was always the second.

## II. Measure how badly, not how many

Counts flatter. Severity discriminates.

Grading shell contact by overlap depth turned 334 "collisions" into 28 real
ones. The 306 that evaporated were a robot bending its own elbow.

## III. Gate the premise before instrumenting the output

Careful measurement downstream of an unchecked assumption yields confident,
precise, and wrong.

Seven of nine skeletons are the wrong shape for their geometry. That was
learned from interpenetration statistics four hours after a one-pass check
would have said so — a check whose computation was already sitting in an
exploratory script, unnoticed.

## IV. One member is a hypothesis, not a class

Four of the day's eight errors were one asset generalised to the corpus:
zero inversions, the bone-density curve, the collision profile, the axis.
All true of `gasket.glb`. None true of the corpus.

The corpus runner exists. Run it before claiming.

## V. Make the machine prove it agrees with the repository

Drift is invisible until diffed. `fleetcore-serve` ran for weeks with an
installed unit older than the repo copy — no functional difference, but the
host described a LAN setup retired 2026-07-13 and the dead `/monad/` prefix
as current fact.

## VI. Build the check into the tool

This is the order the others hang from.

Every wrong reading on 2026-08-05 was made **carefully**. Care is what
produced the confidence. So the corrective is never "be more careful" — it
is to make the ambiguity impossible for a reader to resolve by assumption.

`scripts/sound-the-ship.sh` found in one run what a human had missed five
times in a day.

---

## The asymmetry these orders exist to correct

A crash is honest. It tells you immediately, and it tells you at the moment
of the mistake.

A wrong answer that looks right is the expensive kind, and it costs exactly
as much as the confidence built on top of it before anyone checks. On
2026-08-05 that confidence collapsed eight times, and every single collapse
landed on a check that took under a minute to run.

The reason those checks were not run is the thing worth naming:

> **Surprise prompts checking. Agreement never does.**

When a number matches expectation, that is the moment it goes unexamined —
and it is precisely the moment a second condition producing the same value
becomes invisible. The entire day's error budget went through that gap.

So the standing order for every instrument aboard: **be suspicious of
agreement.**
