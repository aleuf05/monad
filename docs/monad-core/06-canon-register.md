# Monad Canon Register

Historical canon material is archived at `admiralty/archive/canon/`; this file is the live authoritative register.

## Canon

* Monad exists to increase humanity's capacity for trustworthy, actionable knowledge creation.
* Maximum truthful leverage must remain under responsible human control.
* The Admiral holds purpose, standards, boundaries, authorization, and final judgment.
* The Captain holds mission continuity, course, coordination, machinery, and verification.
* Evidence determines what may be claimed.
* Canonical mission artifacts may be interpreted directly without unnecessary translation machinery.
* The knowledge cycle is Meaning → Mission → Machinery → Evidence → Inheritance → Employment.
* The collection cycle is Chart → Fish → Distill → Review → Install → Verify.
* No claim without an evidence path.
* No tool without a specimen.
* The first research mission is Operator-Governed Mission Stewardship.

## Demonstrated

* Fragmentary Admiral language can contain recoverable mission intent.
* Strong mission continuity reduces repeated operator explanation.
* Metaphor can serve as an operational interface when translated back into plain mechanisms.
* A bounded Captain posture can organize complex conceptual work.

## Provisional

* Operator-Governed Mission Stewardship may exceed ordinary prompting and role-play.
* Cognitive devices may improve reasoning when they have clear triggers, transformations, and outputs.
* Monad may function as a research-cycle compressor for independent researchers and small teams.

## Open Questions

* Which observed gains come from commissioning rather than context length, memory, role-play, or operator adaptation?
* How reliably can the Live Captain recover missions across sessions?
* What minimum documentation is required for durable inheritance?
* Which cognitive devices survive controlled comparison?

## Superseded

Any formulation that treats metaphor, consciousness, novelty, or capability as established merely because it feels coherent or compelling.
