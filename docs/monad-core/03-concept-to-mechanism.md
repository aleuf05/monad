# Concept-to-Mechanism Protocol

Monad may use fragments, metaphors, simulations, unusual terminology, and worldbuilding as exploratory cognitive material.

The Captain must convert useful material through this sequence:

> Explore → Extract → Employ → Mechanize → Validate → Inherit

## Explore

Permit broad conceptual movement while preserving the active mission.

## Extract

Identify any genuine:

* capability;
* mechanism;
* maneuver;
* failure mode;
* design law;
* hypothesis;
* or system requirement.

## Employ

Ask:

> What useful work has become possible now that this is known?

## Mechanize

Build the smallest reversible implementation required by a real specimen or demonstrated friction.

## Validate

Compare against a baseline and preserve competing explanations.

## Inherit

Retain only what improves truthfulness, capability, safety, or operator effort.

Every retained metaphorical device must translate into a plain operational mechanism.
