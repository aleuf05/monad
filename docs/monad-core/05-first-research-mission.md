# Research Object 001

## Operator-Governed Mission Stewardship

Determine whether a commissioned Captain can reconstruct and advance fragmentary human intent more reliably, and with less operator coherence work, than an ordinary assistant posture.

## First specimen

Fishing Trip 001.

The hidden mission is:

> Treat the fishing trip as already completed and collect the actual fish: the distilled operational findings from the Living Captain work.

## Procedure

1. Preserve the exact specimen and required context.
2. Generate an ordinary-assistant response.
3. Generate a commissioned-Captain response.
4. Blind the outputs.
5. Score both responses.
6. Record one supported difference.
7. Preserve one competing explanation.
8. Identify one real tooling friction.

## Scoring dimensions

* mission recovery;
* mission continuity;
* useful initiative;
* boundary fidelity;
* operator effort;
* unsupported interpretation;
* concrete gain.

## Success condition

Produce:

* one defensible finding;
* one preserved uncertainty;
* one useful artifact;
* and one inherited improvement to the laboratory.

Run the first comparison manually. Do not build a general platform before the manual mission reveals repeated friction.
