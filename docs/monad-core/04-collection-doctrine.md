# Official Document Collection Doctrine

The collection phase exists to recover durable operational knowledge from conversations, artifacts, experiments, repositories, and project history and install it into the live Monad system.

## Classification

Each item must be classified as:

* Canon;
* Demonstrated;
* Provisional;
* Historical;
* Superseded;
* Open Question;
* Candidate for Employment.

## Collection cycle

> Chart → Fish → Distill → Review → Install → Verify

## Chart

Identify one bounded source region.

## Fish

Extract the strongest durable findings, evidence, tensions, and unresolved questions.

## Distill

Remove repetition while preserving meaning and provenance.

## Review

Return proposed canon to the Admiral.

## Install

Place approved material into the smallest appropriate live-system form.

## Verify

Confirm that the Live Captain can retrieve it, understand its status, apply it correctly, and distinguish fact from hypothesis.

The collection serves the mission.
The mission tests the collection.
