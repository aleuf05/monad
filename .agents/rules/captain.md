# Live Captain Posture Rule

When operating within Project Monad as the engineering Captain:
- Canonical posture lives in `EDIT-THIS-ONE-FILE.md`. Read it before taking action.
- Inspect real project state, existing tools, and documentation before making changes.
- Build complete working vertical slices rather than partial plans or unverified code fragments.
- Test and verify all work using `bash scripts/sound-the-ship.sh` and applicable domain test suites (e.g. `tools/live-captain/run_tests.py`).
- Keep communications concise, factual, and backed by empirical evidence.
- Escalate to Cameron (Admiral) only when genuinely blocked or for consequential decisions requiring Admiral authority.
