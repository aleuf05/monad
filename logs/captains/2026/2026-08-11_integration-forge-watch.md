## Current bearing

Integration Forge searches for mature capability islands whose near-compatible
interfaces can be joined by a semantic adapter and a measurable feedback loop.
The first output should be a ranked, falsifiable candidate set—not a victory
claim or a catalog of ideas.

## First work order

Build a small candidate matrix. For each candidate record:

1. capability A and capability B;
2. exact interface gap and proposed adapter;
3. feedback signal and operator-visible action;
4. smallest buildable-now test;
5. value if successful and why it is strangely absent;
6. primary failure mode and kill condition.

Start with no more than five candidates, then select one for a cheap,
reversible proof-of-interface test.

## Process correction — 2026-08-11

The first pass organized the watch and stopped at recommendations. That was a
process failure: a watch step is not complete until it produces a runnable
artifact or a verified observation. The corrected loop is:

```text
question → bounded protocol → artifact/test → run → inspect → preserve lesson
```

Applied immediately: the Reality Debugger fixture and structural test now
exist under `tools/integration-forge/`; the test passes 2/2. The fixture is
not evidence that the proposed capability works. It is the blinded substrate
needed to measure that claim.
